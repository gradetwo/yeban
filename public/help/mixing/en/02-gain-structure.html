Gain Structure

齐之以味，济其不及，以泄其过。

《左传·昭公二十年》 / Zuo Zhuan, Duke Zhao, Year 20

Translation: Season it to the right taste: add what is lacking and drain off what is excessive. Note: gain staging makes every stage sufficient without overloading it.

Gain structure is about how large the signal should be at each stage. It is not the same as the fader: gain sets the level entering the next stage, while the fader sets how loud this track is relative to the others. Clean gain comes first; the fader only makes sense after that.

Level, gain, fader

  • Level: the size of a signal at a given moment, usually expressed in

    • dBFS or dB.

  • Gain: amplification or attenuation applied by a device. Turning up

    • gain makes the signal stronger, and also makes noise and distortion louder.

  • Fader: the relative volume control on a channel strip. It changes

    • this track's share of the bus, not “fixes distortion”.

Treating the fader as a universal volume key is the most common mixing mistake: when a track is too quiet, push the fader to +6 dB and discover that the device chain was already clipping; when a track is too loud, pull the fader to −30 dB and lose all the dynamics. The correct order is to put the device chain at a sensible level first, then use the fader for relative balance.

“Device-chain gain” in the diagram is the working level inside the devices, not the mixer fader. Yeban currently exposes no editable input-gain knob on the channel strip; gain inside the device chain comes from each effect's own parameters, covered in Chapters 3 and 4.

Readings on Yeban's channel strip

Each channel strip in the mixer console (X / F8) has the following controls and readings. Ranges and defaults come from TrackV3 and the fader mapping code; the interface shows a lossy one-decimal display.

Fader position and dB are not an exponential relationship; the travel maps linearly to −60.0 to +6.0 dB. Moving the fader slightly down from 0 dB changes dB by very little; only near the bottom of travel does it reach −60 dB. Read the number, not just the cap height.

The track meter is a normalised value, not a dBFS number. Use it to see whether a signal exists and whether it is running hot; read precise peak and loudness in the control room. Above 0.8 the meter changes to the warning colour, meaning “near the top”, not “already clipping”. If it stays in the warning zone, fix it before export.

Three principles of gain structure

  1. Gain first, fader second: set a sensible working level in the device

    2. chain, then balance with the fader. If the chain already clips, lowering the fader only makes the clipped waveform smaller; it does not repair it.

  2. Leave headroom at every stage: do not push everything to 0 dBFS.

    3. Leave space for dynamics, parallel summing, and bus processing; during mixing, peak headroom usually matters more than “looking louder”.

  3. Amplify only when needed: louder is not automatically better. When a

    4. track needs to be louder, first check arrangement, timbre, and balance; blind gain boosts noise, distortion, and masking together.

“0 dBFS” is digital full scale, not a standard volume. Yeban's fader 0 dB is only a project reference point; it does not mean the signal is at 0 dBFS. Actual level is determined by the source, the device chain, and the fader together.

Stage-by-stage check

  1. Solo the current track and confirm there is signal; the meter should not be

    2. at zero. If there is no signal, check the clip, mute/solo state, and device bypass first; do not reach for the fader.

  2. Check whether the track meter stays above 0.8. If it does, go back to the

    3. device chain and inspect gain and effect parameters first, then bring the fader to a sensible position.

  3. Balance with faders: start with the lead vocal, drums, and bass skeleton,

    4. then place other tracks around them. Do not push every track from first to last.

  4. Check the master bus and control room: whether the master meter is pinned

    5. near the top, whether integrated/short-term LUFS is in the same range as the reference, and whether peak dBTP has headroom.

  5. Before export, check mute/solo, the reference track, and bypassed devices

    6. once more. Any one of them out of place can make the export differ from what you heard in the project.

Common mistakes

  • Using the fader to fix clipping: the fader can only change the size

    • of an already-clipped signal; it cannot restore the waveform.

  • Pushing every fader up: if every track goes +6 dB, the master bus

    • only clips sooner; relative balance does not require an overall boost.

  • Confusing monitoring volume with mix volume: DIM/MONO/SIDE change

    • only how you monitor. The master fader is project state; do not conflate them.

  • Treating IN:0.0dB as an input-gain knob: it is currently only a

    • static readout in the maximised mixer, with no editable action. To change device gain, edit the relevant effect parameters in the device chain.

Exercise

  1. Choose a track with level variation. Solo it and confirm the meter is not at zero; then check “device-chain gain $$ fader $$ bus” in order.
  2. Pull the fader from 0 dB to $-12$ dB, then restore the same loudness in the device chain; compare transients and noise floor.
  3. Note one section where the meter enters the 0.8 warning zone; check the device chain first, then use the fader for relative balance. Do not fix clipping with the fader.
