快捷键与命令速查

以无厚入有间，恢恢乎其于游刃必有余地矣。

《庄子·养生主》

快捷键让高频动作变得从容；手熟之后，心思留给音乐本身。

夜半有一张**唯一的快捷键策略表**：程序里「帮助 $$ 快捷键速查」显示的那张， 与命令行 yeban-app --print-shortcuts 打印的是同一份。本章按工作流挑出 常用键做导览，方便记忆；它不是第二份权威表——要查全量键位与落地状态，请 以应用内速查为准。

与应用内速查同源的策略表

为什么本章不抄一张全表

策略表随版本演进：哪些键已落地、哪些「键已绑定但宿主尚未实现」，表里都有 逐行标记。手抄一份很快就会过期，也会把「未实现」误写成「可用」。因此本章 只做两件事：给出键位的规范写法说明，以及按工作流挑出高频操作。

规范写法与平台折叠

表里保留跨平台的规范写法 Cmd/Ctrl+：macOS 上渲染成 Cmd+， 其余平台渲染成 Ctrl+。所以你在 Windows 上看到的 Ctrl+S，与 macOS 上的 Cmd+S，是同一条规范键位。带「（未实现）」标记的键表示 键已绑定、也能解析出动作，但宿主还没有对应实现，按下会被拒绝——那不是键坏了。

按工作流分组的常用键

以下键位均取自策略表，按做事的顺序分组。

工程与编辑

  • [Cmd/Ctrl+N] 新建 MIDI 合成器轨。
  • [Cmd/Ctrl+O] 打开工程。
  • [Cmd/Ctrl+S] 保存工程；Cmd/Ctrl+Shift+S 另存为。
  • [Cmd/Ctrl+Z] 撤销；Cmd/Ctrl+Shift+Z 重做。
  • [Tab] 视图切换（仅画布聚焦）；F5 Session 视图，F6 Arrangement 视图。

    • 编排与编辑片段

  • [Space] 播放 / 暂停；Shift+Space 从光标处续播。
  • [Enter] 回到起点；C 循环播放开关。
  • [Cmd/Ctrl+T] 在播放头处切分选中的剪辑。
  • [Cmd/Ctrl+C / V / X] 复制 / 粘贴 / 剪切片段。
  • [Cmd/Ctrl+= / -] 时间轴水平放大 / 缩小。
  • [Cmd/Ctrl+↑ / ↓] 音轨垂直缩小 / 放大。

    • 底部控制台与面板

  • [P / F7] 钢琴卷帘；X / F8 混音控制台；F9 设备机架；F3 控制台设备堆叠。
  • [I] 显隐左侧检查器。
  • [Cmd/Ctrl+Shift+A] 自动化泳道显示。
  • [Cmd/Ctrl+Shift+B] 打开统一浏览器（音色/采样/预设/效果）。
  • [E] 编辑器视图切换。

    • 录音与其他

  • [R] 录制开 / 关。
  • [Cmd/Ctrl+Shift+H] 时光机。
  • [Esc] 关闭命令面板 / 热区透视。

    • 输入法的例外

    在文本输入与 IME 合成态下，除 F5/F6 之外的键都被输入法吞掉，不会触发上面的 动作——这是刻意的，避免打字时误触快捷键。策略表专门有两列说明「画布聚焦」 与「文本输入 + IME 合成态」的差别。
