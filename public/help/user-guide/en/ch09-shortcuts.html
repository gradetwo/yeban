Shortcuts and Command Reference

以无厚入有间，恢恢乎其于游刃必有余地矣。

Zhuangzi, “The Secret of Caring for Life” (《庄子·养生主》)

Translation: “Where there is no thickness to enter what has gaps, there is ample room for the blade to move.” Shortcuts make frequent actions effortless; once the hands know the way, the mind can stay with the music.

Yeban has a single authoritative shortcut policy table: the one shown under Help $$ Shortcuts, which is the same table printed by yeban-app --print-shortcuts. This chapter groups common keys by workflow as a memory aid; it is not a second authoritative table — for the full list and implementation status, use the in-app reference.

The Policy Table Shared with In-app Help

Why this chapter does not copy the full table

The policy table evolves: it marks row by row which keys are implemented and which are "bound but not yet implemented" in the host. A hand-copied table goes stale quickly and can turn "not implemented" into "available". So this chapter does only two things: explain the canonical key notation, and pick out high-frequency operations by workflow.

Canonical notation and platform folding

The table keeps the cross-platform canonical form Cmd/Ctrl+: on macOS it renders as Cmd+, elsewhere as Ctrl+. So Ctrl+S on Windows and Cmd+S on macOS are the same canonical binding. A key marked "(not implemented)" is bound and resolves to an action, but the host has no implementation yet and rejects the press — the key is not broken.

Common Keys by Workflow

The keys below all come from the policy table, grouped in the order you tend to work.

Projects and editing

  • [Cmd/Ctrl+N] New MIDI synth track.
  • [Cmd/Ctrl+O] Open project.
  • [Cmd/Ctrl+S] Save project; Cmd/Ctrl+Shift+S save as.
  • [Cmd/Ctrl+Z] Undo; Cmd/Ctrl+Shift+Z redo.
  • [Tab] View switch (canvas focus only); F5 Session view, F6 Arrangement view.

    • Arranging and editing clips

  • [Space] Play/pause; Shift+Space resume from cursor.
  • [Enter] Return to start; C cycle playback toggle.
  • [Cmd/Ctrl+T] Split selected clip at the playhead.
  • [Cmd/Ctrl+C / V / X] Copy / paste / cut clips.
  • [Cmd/Ctrl+= / -] Zoom the timeline horizontally in/out.
  • [Cmd/Ctrl+Up/Down] Zoom tracks vertically out/in.

    • Bottom console and panels

  • [P / F7] Piano roll; X / F8 mixer console; F9 device rack; F3 console device stack.
  • [I] Toggle the left inspector.
  • [Cmd/Ctrl+Shift+A] Show automation lanes.
  • [Cmd/Ctrl+Shift+B] Open the unified browser (sounds/samples/presets/effects).
  • [E] Toggle editor view.

    • Recording and other

  • [R] Recording on/off.
  • [Cmd/Ctrl+Shift+H] Time Machine.
  • [Esc] Close the command palette / hotspot overlay.

    • The IME exception

    In text input and IME composition mode, every key except F5/F6 is swallowed by the input method and does not trigger the actions above — deliberately, so typing does not fire shortcuts. The policy table has separate columns explaining "canvas focus" versus "text input + IME composition".
