Getting Started

不积跬步，无以至千里。

Xunzi, “Encouraging Learning” (《荀子·劝学》)

Translation: “Without accumulating small steps, one cannot reach a thousand li.” This chapter takes you from installation to your first export, one step at a time: make sound first, refine later.

Yeban is an open-source digital audio workstation: a pure-Rust, low-latency real-time audio engine with a native Slint GUI and a complete MCP tool surface. A human at the desktop and an AI agent can work on the same project side by side. This chapter takes you from installation to your first export, using only features that actually exist.

Installation and First Launch

Choose an installation method

The easiest route is the nightly installers in the Download table of README.md (they track main and are unsigned): an MSI for Windows x86\_64, DMG images for macOS (Apple Silicon and Intel), and DEB packages for Linux (x86\_64 and arm64). Portable .tar.gz archives and SHA256SUMS are on the nightly release page.

Building from source requires Rust 1.99.0 (pinned by rust-toolchain.toml; rustup installs it automatically), a C++ compiler and libclang (yeban-dsp generates bindings with bindgen). On Ubuntu/Debian:


sudo apt-get install -y clang libclang-dev pkg-config libfontconfig1-dev \
  libfreetype-dev libxkbcommon-dev libxkbcommon-x11-0 libwayland-dev \
  libx11-dev libgl1-mesa-dev libasound2-dev
cargo build --release -p yeban-app

Run it with cargo run --release -p yeban-app; add -- --headless on a machine without a display. On a memory-tight machine, build with cargo build --profile release-small -p yeban-app.

The hands-on route: install $$ launch $$ tour $$ arrange $$ audition $$ export

First launch and the onboarding tour

On first launch the app automatically opens the onboarding tour (only when persisted state says it should: it will not reopen once dismissed with “don't show again” or completed). The tour walks through the welcome page, transport bar, arrangement area, piano roll and mixer console, ending with the inspector and sound library. Each step navigates the interface to the area it describes. To see it again, use Help $$ Onboarding Tour.

Interface Overview

Menu bar and transport bar

The menu bar has eight groups: File, Edit, Track, Transport, Mix, View, Diagnostics and Help. The transport bar at the top has play/pause (Space), stop, return to 001.01.000, cycle toggle (C), metronome and count-in, plus the tempo (BPM) display and tap input. On its right is the workspace switcher: Overview, Live Launch, Linear Arrangement and Mixer Console, mapped to number keys 1--4.

Centre: the arrangement area

Each track is a row: the left part is the track header (name, mute/solo, volume), and clips sit on the timeline to its right. Clips can be dragged, resized by their edges, copied (Cmd/Ctrl+C / Cmd/Ctrl+V), cut (Cmd/Ctrl+X) and deleted. Above are the bar ruler and section markers; below you can expand the chord track and automation lanes. Press Tab to open the Clip Launch Matrix (Session view) and fire clips from its grid.

Left: inspector and sound library

The upper-left pane is the channel inspector, showing the selected track's channel strip and device parameters; I toggles it. The lower-left pane is the sound library, where you browse presets and SFZ libraries. The first button in the track-header tool row is the Track Menu, collecting all operations for that track.

Bottom console and edges

Three bottom tabs: piano roll (P / F7), mixer console (X / F8) and device rack (F9); F3 maximises/restores the console. On the right you can open the Control Room (F4), showing master monitoring and loudness readings. The status bar at the bottom shows selection info, live chord recognition, shortcut hints and audio-device status; below it is the song-overview panel. Hovering over a control shows a tooltip; T toggles them.

Your First Project

Start empty, or tour the demo first

A project uses the .yeban extension and is the only project format: one container holds tracks, clips, notes, device chains and the assets they use.

File $$ New Empty Project gives you a project with only the master bus. If you launch without specifying a project, the app opens a demo project (drums, bass, pad, lead, strings, percussion) so you can look around first; it is not your work file, so editing it cannot lose anything of yours.

Create a track, place a clip, play

In an empty project, create an audio track from the Track Menu; pick a preset or SFZ instrument in the sound library and place an audio clip on the timeline. Press Space to play — the transport shows position and tempo. To loop a passage, press C and select a range. If a clip lands in the wrong place, drag it or drag its edge to resize; to split it at the playhead, select it and press Cmd/Ctrl+T.

Save and export

File $$ Save Project (Cmd/Ctrl+S) writes back to the original file; File $$ Save As (Cmd/Ctrl+Shift+S) changes the name or location. Saving is atomic, so a power cut mid-write cannot leave a half-written file.

Full-mix WAV export lives in the File menu. Stem export renders each source-node track into a 32-bit Float WAV in a fixed output directory, and produces a stems-manifest.json index plus a one-line export receipt. The master bus produces no file but is named in the skipped list — that is not a dropped track.
