# yeban-tui — 夜半终端界面

夜半的 TUI 版本：与 Slint GUI 共用同一份工程模型、引擎宿主、快捷键策略表与
主题色值，只换呈现层（ratatui + crossterm，平铺布局，Vi 式模态导航）。

## 接缝路线（路线甲）

`yeban-tui` 依赖 `yeban-app` 库，只调用其**无 Slint 窗口**的部件：

| 能力 | 复用的生产路径 |
| --- | --- |
| 打开工程 | `yeban_app::open::open_project_archive_file`（全保真归档） |
| 保存工程 | `yeban_app::save::{save_project_file, save_archive_file}` |
| 引擎宿主 | `yeban_app::engine_host::EngineHost`（建图、走带、墙钟泵送、电平收集） |
| 导出 WAV | `yeban_app::render_core::render_project_f32_with_assets_under` + `yeban_app::export_wav::write_interleaved_wav` |
| 快捷键 | `yeban_app::cli::shortcut_rows` 策略表 + `yeban_app::input::InputContext` 解析器（与 GUI 同一张表、同一个解析器，不手抄第二份） |
| 推子值域 | `yeban_app::bridge::{FADER_MIN_DB, FADER_MAX_DB}` 与 `parse_hex_color` |

代价：二进制链接 Slint 与 `yeban-app`（从不初始化 GUI）。路线乙（只依赖下层
crate 自写宿主）会重复造引擎接线且被迫手抄键位表，未采用。

走带在无音频设备环境走**控制面墙钟泵送**（`EngineHost::pump_wall_clock`，
与 GUI 控制面同一机制），播放头按真实时间推进。

## 布局（平铺）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：模式徽章 · 工程名 · ▶/■ · 位置 小节.拍.tick · BPM · 脏标记 │
├──────────┬──────────────────────────────┬────────────────────┤
│ 轨道列表  │ 片段网格（小节列，▼=播放头列） │ 检查器（音量/声相/乐器）│
├──────────┴──────────────────────────────┴────────────────────┤
│ Canvas 盲文库点阵：位置进度 + 播放头 + 主总线电平               │
│ 日志行（最后一条回执）                                          │
│ 命令行（: 模式）/ 状态行（-- NORMAL -- 焦点 · 选中轨 · 计数）     │
└──────────────────────────────────────────────────────────────┘
```

## 键位映射表（动作｜GUI 键｜TUI 键）

口径（Wang 2026-11-18 定）：**凡两边都有的动作，TUI 沿用 GUI 的键，不另
发明；Vi 模态键只加在导航与模式层。** TUI 的按键分发先过 GUI 的
`InputContext` 解析器（同一张 `SHORTCUTS` 策略表），解析未命中的键才落到
Vi 层。

| 动作 | GUI 键 | TUI 键 | 状态 |
| --- | --- | --- | --- |
| 播放/暂停 | `Space` | `Space`（同） | 已接（引擎走带） |
| 从光标处续播 | `Shift+Space` | `Shift+Space`（同，小节光标定位后播放） | 已接 |
| 回到起点 | `Enter` | `Enter`（同） | 已接 |
| 保存工程 | `Ctrl+S` | `Ctrl+S`（同）；另有 `:w [path]` 命令形态 | 已接 |
| 另存为 | `Ctrl+Shift+S` | 同键 → 提示用 `:w <path>` | 形态适配 |
| 打开工程 | `Ctrl+O` | 同键 → 提示用 `:open <path>` | 形态适配 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` | 同键；另加 Vi `u`（可带计数）/ `Ctrl+R`（二期 K3 改判） | 已接（走 `UndoPort`，与 GUI 同一撤销栈） |
| 删除选区 | `Delete` / `Backspace` | 同键 → 片段网格焦点下删光标处片段摆放 | 已接（摆放级，经撤销端口） |
| 片段平移 | （GUI 鼠标拖动，无键） | 片段网格焦点下 `H` / `L` 按小节平移（计数 = 小节数） | TUI 新增（经撤销端口） |
| 播放头定位 | （GUI 点标尺） | `:seek <小节号（1 起）>` | TUI 命令 |
| 工程速度 | （GUI 走带区 BPM 框） | `:tempo <BPM>` | TUI 命令（经撤销端口） |
| 选中轨静音 | `M` | `M`（同） | 已接 |
| 选中轨独奏 | `S` | `S`（同） | 已接 |
| 选上一/下一轨 | `Alt+↑` / `Alt+↓` | 同 | 已接 |
| 选中轨音量 ±1.0 dB | `Ctrl+Alt+↑/↓` | 同 | 已接 |
| 选中轨声相 ±0.1 | `Ctrl+Alt+←/→` | 同 | 已接 |
| 视图切换 | `Tab` | `Tab` → 窗格焦点循环（轨道→片段→检查器） | 形态适配（冲突 K6） |
| 混音台开关 | `X` | `X` → 焦点跳检查器 | 形态适配 |
| 编辑器/卷帘开关 | `E` / `P` | 同键 → 焦点跳片段网格 | 形态适配 |
| 时间轴缩放 | `Ctrl+=` / `Ctrl+-` | 同（经 GUI 解析器）→ 每小节列宽 2–8 | 已接 |
| 导出 WAV | （GUI 走菜单，无键） | `:export wav <path>` | TUI 命令 |
| 退出 | （GUI 关窗） | `:q`（脏时拦）/ `:q!` | TUI 命令（冲突 K5） |
| 片段切分 | `Ctrl+T`（播放头处切分选中剪辑） | `Ctrl+T`（同）→ 切分光标处片段 | 已接（三期；组合与 GUI 共用 `host::clip_split_ops_for`，经撤销端口） |
| 片段复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 同键 → 光标处片段；粘贴落选中轨的小节光标处 | 已接（三期；组合照 GUI `clipboard_*`，经撤销端口） |
| 片段改名 | （GUI 未接；MCP 有 `setClipName`） | 片段网格焦点 `i` → Insert 改名（`Op::SetClipName`） | TUI 新增（三期） |
| 音符编辑 | 钢琴卷帘（GUI） | 片段网格焦点 `n` / `:notes` 开音符视图（Esc 关） | 已接（三期；视图内键位见下） |
| 片段池管理 | （GUI 无池管理面；MCP 有 `removeClip`） | `:pool` 开池视图（Esc 关），视图内 `Delete` 删条目 | TUI 新增（三期；被引用时模型以 `ClipInUse` 拒绝） |

Vi 层新增（仅导航与模式，不占共享动作）：

| TUI 键 | 作用 |
| --- | --- |
| `h` / `l` | 小节光标左/右移（片段网格的列光标，顶栏位置与续播定位以它为准） |
| `j` / `k` | 选轨下/上移（与 GUI 的 `Alt+↓/↑` 并存，同为选轨） |
| `gg` / `G` | 跳首/尾（轨道焦点=首/尾轨，片段焦点=首/尾小节） |
| `1`–`9` 计数前缀 | 动作重复计数（如 `5j`、`3u`）；`0` 不作计数起始（同 vi） |
| `u` | 撤销（二期 K3 改判；与 GUI 的 `Ctrl+Z` 同落一个撤销端口） |
| `Ctrl+R` | 重做（二期 K3 改判；GUI 表无此格，为 TUI 自加键） |
| `i` | 进 Insert 改名（轨道/检查器焦点 = 轨道名；片段网格焦点 = 片段名，三期） |
| `:` | 进 Command 命令行 |
| `Esc` | 回 Normal / 清计数与半成品序列；列表视图开着时先关视图（三期） |
| `n` | 片段网格焦点下开音符视图（三期；共享表 PassThrough、Vi 层未占） |

音符视图内（片段网格的内容变体，不是新窗格）：

| TUI 键 | 作用 |
| --- | --- |
| `j` / `k`、`gg` / `G` | 选上/下一个音符、首/尾音符（Vi 动作按视图分流） |
| `h` / `l`、方向键 `←` / `→` | 移动选中音符的时间（一格 = 240 tick；方向键走 GUI 的 `NudgeSelection`） |
| `J` / `K`、方向键 `↑` / `↓` | 移动选中音符的音高（±1 半音；`Shift+↑/↓` = ±12，与 GUI 同） |
| `a` | 在小节光标处加音符（音高随选中音符、时值一拍、力度 100） |
| `Delete` / `Backspace` | 删选中音符（`DeleteSelection` 按视图分流） |
| `<` / `>` | 时值 ∓/± 一拍（下限 240 tick） |
| `-` / `+` | 力度 ∓/± 10（视图内分流；视图外仍是缩放） |
| `Esc` | 返回片段网格 |

片段池视图内：`j`/`k`/`gg`/`G` 选条目，`Delete` 删选中条目
（`Op::RemoveClip`；有摆放引用时模型拒绝、日志如实报），`Esc` 返回。

Command 命令集：`q`、`q!`、`w [path]`、`wq [path]`、`play`、`stop`、
`rewind`、`seek <小节号（1 起）>`、`tempo <BPM>`、`export wav <path>`、`open[!] <path>`、
`demo[!]`、`notes`、`pool`。

## 冲突清单（逐条，按「共享动作从 GUI、导航从 Vi」解）

- **K1 数字键**：GUI 裸数字 `1`–`5` = 选工具；TUI v1 无工具系统，数字归
  Vi 计数前缀，选工具记为未接。将来 TUI 加工具系统时须另行裁决（计数与
  选工具不可同占裸数字）。
- **K2 音量键**：早期 brief 曾定检查器 `+`/`-` 调音量，**作废**——改用 GUI
  的 `Ctrl+Alt+↑/↓`（音量）与 `Ctrl+Alt+←/→`（声相）；`+`/`-` 不作音量键。
- **K3 撤销**：一期裁决「不用 Vi 的 `u`、只从 GUI 键」且 v1 未接撤销栈。
  二期（Wang 2026-11-18 令推进完善）改判：GUI 键仍是基础，TUI 再加自己的
  Vi 键 —— `u`（可带计数）撤销、`Ctrl+R` 重做。编辑（静音/独奏/音量/声相/
  改名/片段平移与删除/速度）一律经 `UndoPort::commit_ops` 提交，与 GUI 共用
  同一个撤销端口与同一种 `Op`；保存时提交图谱写回 `history.dag`，重开可恢复。
- **K4 `Enter`**：从 GUI = 回到起点；Insert/Command 模式内 Enter 是模式内
  提交，不在此列。
- **K5 退出**：裸 `q` 不绑定（避免误退），只认 `:q` / `:q!`。
- **K6 `Tab`**：GUI = 视图切换；TUI 无 GUI 的视图集，适配为窗格焦点循环。
- **K7 列表视图（三期）**：音符/片段池视图是片段网格窗格的内容变体，
  不是新窗格（Tab 循环仍三格）。视图内删除/微移复用共享表的
  `DeleteSelection` / `NudgeSelection` 在分发层按视图定落点；裸 `-`/`+`
  只在音符视图内分流为力度。新占键只有裸 `n` 与视图内的
  `a`/`<`/`>`/`J`/`K`（共享表 PassThrough 或未占，视图外不拦截）。

## 本轮真实测试修复（2026-11-20）

| 缺口 | 修复 |
| :--- | :--- |
| `[yeban-app]` 诊断直写 stdout/stderr，撕碎整屏 | `EngineHost::set_quiet_diagnostics`；TUI 装配置位，音频注入读数改走日志行 |
| 音频片段永不进引擎（`set_audio_asset_source` 未接） | 装配时把归档 `assets` 的字节接成来源；判据 `tui_fixes::demo_audio_assets_reach_the_engine` |
| `:export wav`（无路径）把 `wav` 当文件名写盘 | 按词法解析，无路径 ⇒ 报用法 |
| `:seek` 越界不钳位 | 钳到最后一小节并提示「工程只有 N 小节」 |
| `:tempo` 0 只回「用法」 | 给合法范围 20–300，越界说明原因 |
| 改名预填旧名无提示 | 进入即提示，并支持 `Ctrl+U` 清空 |
| 非片段网格按 `n` 静默 | 提示「先 Tab 到片段网格」；状态行补 `n 音符` |
| WAV 错误文案不可执行 | 先探测父目录，报「目录不存在…先创建或换路径」 |

## v1 已知缺口

- （三期已关闭）切分/复制/粘贴片段、片段改名、音符编辑、片段池条目删除
  均已接（核心能力审计见 `docs/phase3-core-audit.md`，五项核心全部已有，
  本线只做接线）。片段删除仍分两级：网格里 Delete 删摆放，池条目在
  `:pool` 视图里删（无引用才删得掉）。
- 电平只显示主总线峰值（单条竖条）；逐轨电平、波形未画（Canvas 底栏已用
  盲文库点阵画位置进度 + 播放头 + 主总线电平）。
- 录音、节拍器、循环播放、AI 抽屉等 GUI 动作未接。
- 实时播放仍无音频设备输出（控制面墙钟）；音频片段已接字节，可进引擎与离线导出。
- 中文轨道名在轨道列表按显示宽度对齐（unicode-width），片段网格内不显示
  片段名（只画占用块），长工程名在顶栏可能截断。
- 无音频设备时无声（控制面模式）；有音频设备的实时输出未接（v1 只走
  墙钟泵送 + 离线渲染导出）。
