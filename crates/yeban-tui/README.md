# yeban-tui — 夜半终端界面

夜半的 TUI 版本：与 Slint GUI 共用同一份工程模型、引擎宿主、快捷键策略表与
主题色值，只换呈现层（ratatui + crossterm，平铺布局，Vi 式模态导航）。

## 接缝路线（路线甲）

`yeban-tui` 依赖 `yeban-app` 库，只调用其**无 Slint 窗口**的部件：

| 能力 | 复用的生产路径 |
| --- | --- |
| 打开工程 | `yeban_app::open::open_project_archive_file`（全保真归档） |
| 保存工程 | `yeban_app::save::{save_project_file, save_archive_file}` |
| 引擎宿主 | `yeban_app::engine_host::EngineHost`（建图、走带、墙钟泵送、电平收集） |
| 导出 WAV | `yeban_app::render_core::render_project_f32_with_assets_under` + `yeban_app::export_wav::write_interleaved_wav` |
| 快捷键 | `yeban_app::cli::shortcut_rows` 策略表 + `yeban_app::input::InputContext` 解析器（与 GUI 同一张表、同一个解析器，不手抄第二份） |
| 推子值域 | `yeban_app::bridge::{FADER_MIN_DB, FADER_MAX_DB}` 与 `parse_hex_color` |

代价：二进制链接 Slint 与 `yeban-app`（从不初始化 GUI）。路线乙（只依赖下层
crate 自写宿主）会重复造引擎接线且被迫手抄键位表，未采用。

走带在无音频设备环境走**控制面墙钟泵送**（`EngineHost::pump_wall_clock`，
与 GUI 控制面同一机制），播放头按真实时间推进。

## 布局（平铺）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：模式徽章 · 工程名 · ▶/■ · 位置 小节.拍.tick · BPM · 脏标记 │
├──────────┬──────────────────────────────┬────────────────────┤
│ 轨道列表  │ 片段网格（小节列，▼=播放头列） │ 检查器（音量/声相/乐器）│
├──────────┴──────────────────────────────┴────────────────────┤
│ Canvas 盲文库点阵：位置进度 + 播放头 + 主总线电平               │
│ 日志行（最后一条回执）                                          │
│ 命令行（: 模式）/ 状态行（-- NORMAL -- 焦点 · 选中轨 · 计数）     │
└──────────────────────────────────────────────────────────────┘
```

## 键位映射表（动作｜GUI 键｜TUI 键）

口径（Wang 2026-11-18 定）：**凡两边都有的动作，TUI 沿用 GUI 的键，不另
发明；Vi 模态键只加在导航与模式层。** TUI 的按键分发先过 GUI 的
`InputContext` 解析器（同一张 `SHORTCUTS` 策略表），解析未命中的键才落到
Vi 层。

| 动作 | GUI 键 | TUI 键 | 状态 |
| --- | --- | --- | --- |
| 播放/暂停 | `Space` | `Space`（同） | 已接（引擎走带） |
| 从光标处续播 | `Shift+Space` | `Shift+Space`（同，小节光标定位后播放） | 已接 |
| 回到起点 | `Enter` | `Enter`（同） | 已接 |
| 保存工程 | `Ctrl+S` | `Ctrl+S`（同）；另有 `:w [path]` 命令形态 | 已接 |
| 另存为 | `Ctrl+Shift+S` | 同键 → 提示用 `:w <path>` | 形态适配 |
| 打开工程 | `Ctrl+O` | 同键 → 提示用 `:open <path>` | 形态适配 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` | 同键 → 如实报未接（v1 无撤销栈） | 缺口（见下） |
| 选中轨静音 | `M` | `M`（同） | 已接 |
| 选中轨独奏 | `S` | `S`（同） | 已接 |
| 选上一/下一轨 | `Alt+↑` / `Alt+↓` | 同 | 已接 |
| 选中轨音量 ±1.0 dB | `Ctrl+Alt+↑/↓` | 同 | 已接 |
| 选中轨声相 ±0.1 | `Ctrl+Alt+←/→` | 同 | 已接 |
| 视图切换 | `Tab` | `Tab` → 窗格焦点循环（轨道→片段→检查器） | 形态适配（冲突 K6） |
| 混音台开关 | `X` | `X` → 焦点跳检查器 | 形态适配 |
| 编辑器/卷帘开关 | `E` / `P` | 同键 → 焦点跳片段网格 | 形态适配 |
| 时间轴缩放 | `Ctrl+=` / `Ctrl+-` | 同（经 GUI 解析器）→ 每小节列宽 2–8 | 已接 |
| 导出 WAV | （GUI 走菜单，无键） | `:export wav <path>` | TUI 命令 |
| 退出 | （GUI 关窗） | `:q`（脏时拦）/ `:q!` | TUI 命令（冲突 K5） |

Vi 层新增（仅导航与模式，不占共享动作）：

| TUI 键 | 作用 |
| --- | --- |
| `h` / `l` | 小节光标左/右移（片段网格的列光标，顶栏位置与续播定位以它为准） |
| `j` / `k` | 选轨下/上移（与 GUI 的 `Alt+↓/↑` 并存，同为选轨） |
| `gg` / `G` | 跳首/尾（轨道焦点=首/尾轨，片段焦点=首/尾小节） |
| `1`–`9` 计数前缀 | 动作重复计数（如 `5j`）；`0` 不作计数起始（同 vi） |
| `i` | 进 Insert 改名（轨道/检查器焦点） |
| `:` | 进 Command 命令行 |
| `Esc` | 回 Normal / 清计数与半成品序列 |

Command 命令集：`q`、`q!`、`w [path]`、`wq [path]`、`play`、`stop`、
`rewind`、`export wav <path>`、`open <path>`、`demo`。

## 冲突清单（逐条，按「共享动作从 GUI、导航从 Vi」解）

- **K1 数字键**：GUI 裸数字 `1`–`5` = 选工具；TUI v1 无工具系统，数字归
  Vi 计数前缀，选工具记为未接。将来 TUI 加工具系统时须另行裁决（计数与
  选工具不可同占裸数字）。
- **K2 音量键**：早期 brief 曾定检查器 `+`/`-` 调音量，**作废**——改用 GUI
  的 `Ctrl+Alt+↑/↓`（音量）与 `Ctrl+Alt+←/→`（声相）；`+`/`-` 不作音量键。
- **K3 撤销**：不用 Vi 的 `u`；从 GUI 的 `Ctrl+Z` / `Ctrl+Shift+Z`。v1 未接
  撤销栈（编辑为直接改文档 + 发布引擎，无 UndoPort），按下如实报未接。
- **K4 `Enter`**：从 GUI = 回到起点；Insert/Command 模式内 Enter 是模式内
  提交，不在此列。
- **K5 退出**：裸 `q` 不绑定（避免误退），只认 `:q` / `:q!`。
- **K6 `Tab`**：GUI = 视图切换；TUI 无 GUI 的视图集，适配为窗格焦点循环。

## v1 已知缺口

- 撤销/重做未接（无撤销栈）；删除/切分/复制等编辑动作未接（按键落到
  分发层会如实记日志「未在 TUI v1 实现」，不假装执行）。
- Insert 模式只做了轨道改名；片段改名、音符编辑未做。
- 电平只显示主总线峰值（单条竖条）；逐轨电平、波形未画（Canvas 底栏已用
  盲文库点阵画位置进度 + 播放头 + 主总线电平）。
- 录音、节拍器、循环播放、AI 抽屉等 GUI 动作未接。
- 中文轨道名在轨道列表按显示宽度对齐（unicode-width），片段网格内不显示
  片段名（只画占用块），长工程名在顶栏可能截断。
- 无音频设备时无声（控制面模式）；有音频设备的实时输出未接（v1 只走
  墙钟泵送 + 离线渲染导出）。
