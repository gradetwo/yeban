# 界面字体许可说明 (Font Licenses)

夜半 (Yeban DAW) 界面所引用的开源字体均遵循严格的自由软件许可：

## 1. Inter 字体家族
- **版本**：4.0+
- **作者**：Rasmus Andersson
- **许可证**：SIL Open Font License 1.1 (OFL-1.1)
- **用途**：应用主界面标签、按钮、菜单等 UI 文本渲染

## 2. JetBrains Mono 字体家族
- **版本**：2.304+
- **作者**：JetBrains
- **许可证**：SIL Open Font License 1.1 (OFL-1.1)
- **用途**：走带条精确时间码（SMPTE / Bar:Beat:Tick）、参数数值输入液晶屏及自动化数据列表渲染

---
所有字体文件的完整原始许可证文本保留于字体所在目录中。
