# 工厂工程模板（随应用分发）

本目录是夜半的**工厂模板目录**：存进这里的 `.yeban` 工程文件就是模板，
用户在「文件 → 从模板新建…」里能直接选用（照 Logic Pro 的模板机制：
模板不是新格式，就是存进模板目录的工程文件）。

发布包内路径与源码树不同，但目录结构相同：

- macOS `.app`：`Contents/Resources/assets/templates/`
- Linux `.deb`：`/usr/share/yeban/assets/templates/`
- 源码树直跑：`assets/templates/`

## 目录结构（三级分类）

```text
assets/templates/
  <曲风>/
    <子曲风>/
      <模板名>.yeban
```

- 只认恰好三级深度的 `.yeban` 文件；其它深度与其它后缀不进选择器。
- 同名判定以三级路径为准：不同子曲风下可以同名。
- 从模板新建打开的是未命名副本，编辑永不回写这里的文件。

模板**内容**（只留配置、去掉片段内容的工程）由后续内容线按市场需求
定序添加，本目录先行占位；为空时选择器的「工厂模板」组如实不出现。
