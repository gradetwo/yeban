# ADR-0047 — 旋律**动机**（motif／句法／终止式）：theory 与 MCP 两侧都**没有**对应概念，要不要新增属产品裁决

- **状态**: **Proposed**（待人类批准；⛔ 集成者代签 —— 本票不改任何代码，只把实测边界与三条可选路线登记成可批可驳的裁决）
- **决定者**: 待人类裁决（集成者提出）
- **关联**: `ADR-0038`（旋律音域）、`ADR-0039`（旋律跳进）、`ADR-0045`（旋律种子）、
  `ADR-0042`（和声音级覆盖性，同类"Proposed 待批"的写法先例）、`MCP-TOOL-005`（`yeban_propose_section`）
- **卡住的票**: `G8f` 的**动机半片**（音域半片已由 `ADR-0038` 落地）；`HD-70` 的审计口径。
- **实现落点**: ⛔ 本票无落点。若批 `D2`，落点在 `crates/yeban-theory/src/melody.rs`（纯整数后处理）；
  若批 `D3`，须另开 ADR 并先有登记数据来源。

## 背景（先测后改，AGENTS.md §6）

**这个数字在数什么**：`crates/yeban-theory` 与 `crates/yeban-mcp/src` 里，与
动机/句法/终止式相关的**音高组织概念**（⛔ 数 `Motif` 这个**片段默认名**字符串）的个数。

现读（2026-10-28，`grep -rni "motif\|motive\|phrase"`）：

1. **theory 侧唯一一处**是**边界声明**：`crates/yeban-theory/src/melody.rs:16-18`
   ——"旋律型 (motif)、句法、终止式一律不做：那需要登记数据或人类审美裁决，本 crate 无权发明"。
2. **MCP 侧唯一一处**是 `project_create.rs:143/156` 的**片段默认名** `"Motif"`（只是一个名字，
   ⛔ 任何生成语义）。⇒ 两侧都**没有**"重复动机""动机变形""终止式"等**可测**结构。
3. 既有旋律能力已闭合的是**约束轴**：音域（`ADR-0038`）、跳进上界（`ADR-0039`）、
   取音种子（`ADR-0045`）、每小节音头数（`ADR-0036`）。这些⛔ 产生"句法"，
   只是把**同一套候选集**收窄 ⇒ 换参数换的是"音高/密度"，⛔ 换"前后呼应"。

⇒ 症状不是缺陷而是**能力边界**：想让旋律"有动机"的 Agent 在现有契约里**没有任何键**可用，
且任何"用种子凑重复"的做法都不可测（同一种子只保证逐字节确定，⛔ 保证音高轮廓重复）。

## 三条路线（人类择一）

### D1 —— 明确不做（关闭该半片）

- 做法：把 `G8f` 动机半片标为"**明确不做**"，`melody.rs` 的边界声明原样保留。
- 代价：Agent 侧的"动机"诉求**永远**没有出口；`HD-70` 按"不接"登记。
- 可测性：无需新判据（现状即结论）。

### D2 —— 最小动机：**轮廓重复**（推荐；纯整数、可独立测量）

- 做法：新增一个**可选**键（如 `melodyMotifBars`，单位＝小节数，界 `1..=bars`），语义钉死为
  **"第 k 个动机窗内的音高轮廓 = 第 1 个动机窗的轮廓（按音阶音级差平移，不越音域）"**。
  不引入任何流派表、不引入"好听"判定；`ADR-0038` 的音域与 `ADR-0039` 的跳进**仍然优先**
  （平移后越界 ⇒ 回退该格的既有候选逻辑并**如实计数**回退格数）。
- 为什么可测：判据可逐格比较**音级差序列**是否相等 + 越界回退计数为 0（或点名回退格）。
- 代价：这是**新增音乐能力**（不是开放既有实参）⇒ 必须在 README 与 schema 里写清"轮廓≠动机变形"；
  且"重复"本身是审美选择，**批准即等于采纳入这条最小定义**。
- ⚠ 若批 D2，"缺省"必须逐字节保持现状（不传键 ⇒ 与今日输出完全相同），否则违反 `ADR-0016` 口径。

### D3 —— 完整动机/句法/终止式

- 做法：单独立项，先解决**登记数据来源**（动机库？流派规则？）与**审美裁决机制**。
- 代价：本仓库没有可引用的登记数据先例用于"好听的旋律"；`ADR-0042` 的教训是
  缺数据时**静默丢音级**比报错更坏。⇒ D3 不建议在无数据来源前启动。

## 建议

**D1 或 D2，二选一**；D3 留待有登记数据来源时另开 ADR。
无论选哪条，本票都**不**授权集成者自行选择 —— 批准后按所选路线另开实现票并补判据。

## 后果（若批准 D2）

- `schemas/mcp-tools.schema.json` 与 `tools.rs` 的 `yeban_propose_section` 各加一个可选键；
- theory 侧新增纯整数后处理与单元判据（轮廓相等 + 回退计数）；
- MCP 侧判据：传键前后**逐字节不同**、不传键时**逐字节相同**（`ADR-0016` 口径）。
