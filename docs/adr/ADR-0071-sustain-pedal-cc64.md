# ADR-0071 — CC64 延音踏板语义（保持 + 半踏板）

- **状态**: Proposed (依 MIDI 1.0 与 Logic Pro 通行规范裁决)
- **决定者**: Agent (依据人类常设授权："遇到需要裁决的、参考 Logic Pro 自己裁决")
- **关联**: `MODEL-AST-002`（`AutomationTarget::MidiCc`、`AutomationLane`）；
  `crates/yeban-engine/src/snapshot.rs`（`project_schedules`、`pedal_hold_end_tick`）；
  `crates/yeban-engine/tests/sustain_pedal.rs`；
  ADR-0015 D4（CC64 导入进 `MidiCc{64}` 泳道、导出原样写回）。
- **日期**: 2026-11-12

## 背景

CC64 延音踏板此前在夜半里只是一条数值泳道：`MidiCc{64}` 曲线能画、能导入导出、
能被 SFZ 的 `*_oncc64` 读到，但**没有任何音符保持行为**。一颗音符松键即进释放段，
不管踏板是否踩下。缺口报告（`~/workspace/research/yeban-midi-humanize-gaps.md`
§3a G6）把这一项列为 CC 区唯一改持续音响行为的项。

Logic Pro 对照：Sustain 踏板事件是标准 MIDI CC64；踩下期间松键的音符继续发声，
抬起时释放；半踏板（中间值）给出部分延音。

## 决定

### D1: 踏板语义落在调度投影层（`project_schedules`），tick 域

音符的发声终点在全仓只有一个事实源：快照投影 `project_schedules` 产出的
`ScheduledNote.end_sample`（实时走带与离线导出**同源**；SFZ 与复音两支路都读它；
`held_before` 的"按住数"也读它）。踏板保持因此在投影期、tick 域做：

- 每轨取自己的 `MidiCc{64}` 泳道，`read_enabled` 且有点才生效；
- 音符终点按 [`pedal_hold_end_tick`] 延后，再走 `sample_at` 换算成帧
  （变速工程同样正确；`held_before` 因此也把踏板按住的音符算作"按住"）；
- 不新增模型字段、不新增 MCP 工具、不新增随机源（全过程确定性）。

代价：声部层（`SfzVoicePool` / `PolySynth`）看不到踏板状态 —— 保持只能表达为
"终点延后"，表达不了"释放段拉长"（半踏板在真实钢琴上首先是制音器半抬、
释放变慢）。释放段拉长需要声部层接踏板探针，是后续线。

### D2: 通断阈值 64（MIDI 1.0）

`v >= 64` = 踩下，`v <= 63` = 抬起（`0..=63` 关 / `64..=127` 开是 MIDI 1.0 的
标准口径，Logic Pro 同口径）。全踏板时音符终点延到曲线**首次跌破 64** 的 tick：
相邻点对之间的线性弦上求交点（`Linear` 段精确；缓动段为弦近似，见 D1 的代价）。

踏板到数据末仍未抬起时，延到**本轨内容末 tick**（全部摆放里最长的音符末 tick，
摆放裁剪后）：⛔ 不是无限延长 —— 调度表必须是有限的。

### D3: 半踏板 = 保持区间按深度线性缩放

`0 < v < 64` 时，终点延到曲线**回到 0** 的 tick，但保持区间按 `v / 64` 缩放：

- `v → 0` 时延量 → 0（与"无踏板"连续）；
- `v → 64` 时延量 → 全踏板量（与 D2 在阈值处连续）；
- 中间值线性过渡，**无跳变**（细粒度阻尼规则：偏差不得突变）。

这是一个**时长模型**，不是制音器物理模型：它回答"音符多响多久"，不回答
"释放段多慢"。D1 的代价里已登记后者需声部层探针。

### D4: 只延每份拷贝的最后一个 ratchet 脉冲；摆放裁剪不管踏板延量

- `ratchet` 把音符拆成 N 个脉冲时，只延最后一个脉冲的终点 —— 细分节奏
  不糊成一片（前面的脉冲按原格结束）。
- 摆放裁剪（`project_schedules` 第 1 条）管的是**记谱时值**，踏板延的是
  **发声终点**：延后终点不被摆放区间裁剪，上限只由踏板抬起 tick 与本轨
  内容末 tick 定。终点永不短于原终点。

### D5: 向后兼容

无 CC64 泳道 / `read_enabled == false` / 空泳道 ⇒ 本轨调度与接线前**逐位相同**
（`pedal_lane` 为 `None` 时投影代码不执行）。既有工程（无踏板数据）导出的
字节与渲染逐位不变。

## 影响

- 表现力：真实演奏的踏板数据（导入的 MIDI、画的 CC64 曲线）第一次真的让音符
  保持；半踏板有可听的中间态。
- 确定性：同一泳道同一终点 ⇒ 同一输出；seed 规则不适用（无随机源）。
- 判据：`snapshot.rs` P1–P7（投影终点样本）+ `tests/sustain_pedal.rs` S1/S2
  （复音支路真的在保持窗出声、抬起后回到静音）。
