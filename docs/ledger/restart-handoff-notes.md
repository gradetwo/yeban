## 6. 纪律（本会话实证有效，请继续用）

- 判定来源**只有两种**：真实运行的结果 · 读回的 CI 判决。**未读回＝没有判决**。
- 读判决时**同时按 `head_sha` 和 `--workflow=ci.yml` 过滤**（同一 sha 可能有两个 run）。
  `skipped` ≠ 绿。
- 每个提交**一次一推**（多提交同推时，只有 tip 拿到 run ⇒ 用
  `git push origin <sha>:refs/heads/line/verdict-<name>` 给中间提交补判决，读完删分支）。
- **推之前先 `git fetch` ＋ `rebase origin/main`**；同一轮里若前面的线推进了 `main`，
  后面的线会被拒（非快进）⇒ 单独重试再 rebase 一次。
- 读一个批次前**先 `job_output`**：终止批次会**永久丢掉**它未读的报告。
- 探针一律放 `/tmp` 并用 `python3 -B`，⛔ **不要**写进 `crates/**/tests/**`。
- 报统计数字时**贴对照读数**（同模式下其它成员的非零计数），以证明扫描模式有效。
