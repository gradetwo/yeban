# 阶段状态表（`ROAD-M-1-001` … `ROAD-M4-010`，46 项）

> **这份文件回答"每个阶段的路线图项现在什么状态、还剩几项"。**
> 它由 `scripts/gates/check_phase_status.py` 在每次 `run-gates.sh light` 里机械校验
> （照 `docs/ledger/gate-status.md` 的成功先例：那张表管门禁，这张表管阶段项）。

维护纪律（**必须遵守**，否则这张表会变成谎言）：

1. 状态的取值**只有三个**：`已完成` / `部分` / `PENDING`（与 `gate-status.md` 同一套词，便于互相引用）；
2. 标 `已完成` / `部分` **必须**给出**可复跑的判据**（run id / 命令 / 测试名 / 台账的路径 + 小节号）；
3. `PENDING` 必须写清**为什么**，并给出"它确实还不存在"的可复跑痕迹
   （例如 `ls <目录>` 报不存在、`grep` 命中 0）—— **不许把"没查"写成 `PENDING`**；
4. `ADR-0001 D7`：**不具备条件的一律 `PENDING`**；也不许把"我觉得做完了"写成 `已完成`；
5. 状态变化时**同一次提交**里改这张表，并同步改末尾的汇总计数（守卫会校验两者一致）。

- 某个 `ROAD-*` 项**等价于**某条门禁时，本表**只写门禁 ID**、**不复制**它的状态与证据。
