# 待人类裁决清单（Human Decisions）

> **这是唯一需要人类决定的事项清单。** 每项有一个稳定的 `HD-nn` 编号，答起来只需"`HD-03` 选 B"这种形式。
>
> 维护纪律（由 `scripts/gates/check_decisions.py` 机械守卫，已接进 `run-gates.sh light`）：
> 1. **每条 ADR 里标了 `Proposed` / `待人类` / `需人类` 的裁决，必须在这里有一行**（否则门禁红）；
> 2. 每行必须写清 **选项 / 建议 / 不决定的后果** —— 只写"请裁决"没有意义，人类需要看到代价；
> 3. **Agent 不等裁决也能继续推进**：每行都必须写明"当前处置"（我们按什么在跑），因此本清单里的任何一项
>    **都不构成单点阻塞**（这也正是目标里"绝不允许出现单点阻塞"的要求）；
> 4. 人类决定后，把结论写回对应 ADR/规范并在本行标注 `✅ 已裁决 <日期> <结论>`（历史保留，不删行）。
