# 声音设计 Skill（物理优先的声音思维）

> 核心命题：**声音是物理，不是偏好。**（"The music becomes a question of physics, not preference."）
> 一切"活"的音色都来自**不稳定性被当作材料**，而不是被修正掉。

## 1. 第一原则：不完美是材料

数字音频的默认状态是"绝对频率、绝对重复、绝对干净"——这三件事恰好是听感死亡的三个原因。

设计任何音色前，先回答：

| 问题 | 如果答案是"没有" |
|:--|:--|
| 这个声音哪里在**漂**？ | 音高/相位/滤波在微观上必须持续移动 |
| 这个声音**第二次**和第一次哪里不同？ | 重复必须带损耗或偏移 |
| 这个声音的**空间**由什么构成？ | 空间不能只靠一个混响插件贴在末尾 |
| 这个声音的**噪声底**在哪？ | 无噪声底的数字音源听起来"塑料" |

## 2. 五个可操作概念

### 2.1 漂移与拍频（Drift & Beating）

模拟电路永远守不住绝对频率（温度、电压、元件公差）。数字里要**主动重建**这件事：

- ** unison 漂移**：4 个振荡器各自独立漂移，**关闭相位重置（phase retrigger = off）**，每个音都是独立事件
- 漂移量：±3 ~ ±12 音分（pad 取大值、bass 取小值 ±2~4）
- 多声部同音时，相位关系缓慢开花/消散 → 产生"呼吸式调制"，这是拍频，不是 LFO
- **关键区别**：全局 LFO 是"整齐的抖动"（一听就假）；每声部独立随机漂移才是"活的湖面"
- 验收：solo 一个持续和弦 20 秒，频谱在基频附近应缓慢爬行，不是静止也不是规律摆动

### 2.2 自发重复（Spontaneous Repetition）

"重复从不真正重复"（repetition that never quite repeats）。四层实现，从便宜到彻底：

1. **采样轮替**：同音多采样随机/顺序轮替（round-robin），至少 4 个变体
2. **微偏移**：每次触发的时间偏移 ±3~15 ms、音高 ±2~6 音分、力度 ±6
3. **滤波漂移**：滤波截止频率随事件缓慢游走（不是 LFO 同步）
4. **反馈损耗**：延迟/混响的每次回归都变暗、变失谐、变薄（见 2.4）

⚠️ **随机必须有稳定身份键**：随机种子要绑定 `(事件序号, 音高, 声道)` 这类可复现的量，否则：
- 渲染结果不可复现（无法 A/B、无法交付）
- 分段渲染时每段随机重置 → 随机效果只在第一段出现

> 这是实践中最容易翻车的地方：**"随机"和"可复现"不是对立的，用确定性哈希派生随机即可。**

### 2.3 氛围即结构（Atmosphere as Structure）

空间不是后期加的装饰，是作曲材料。三层建法：

| 层 | 手段 | 参数经验 |
|:--|:--|:--|
| 近场 | 干声 + 短早期反射 | pre-delay 5–20 ms，别糊掉瞬态 |
| 中场 | 板式/房间混响 | decay 0.8–2.0 s，低频衰减单独设短（防浑浊） |
| 远场 | 长尾 + 反馈延迟 | decay 4–12 s，高通 200–400 Hz 去掉泥 |

- 混响**只给需要"位置"的声部**；律动声部保持干声
- 空间的"深度"来自**干湿比例随段落变化**，不是固定一个值
- 想要"雾"：给混响尾加轻微失谐（chorus ±5 音分）和低通扫动

### 2.4 延迟是滤波器，反馈是随机游走

磁带延迟的本质：**延迟时间同时是低通截止、也是噪声底**——磁粒子每秒通过磁头的数量变少，高频消失、嘶声上升。

数字复刻要点：

- 延迟时间拉长时，**同步**降低反馈环内的低通截止（如 200 ms → 8 kHz，600 ms → 2.5 kHz）
- 反馈环内加**每圈失谐**（±3~10 音分递减）和**每圈衰减高频**，让每次回归都是"上一次的影子"
- 反馈量控制在 0.55–0.75；>0.85 会自激成啸叫（除非你要）
- 加**噪声底随反馈增益上升**（-60 dB 量级起步），这条是"磁带味"的关键，多数人漏掉
- 复用技巧：把同一延迟的两路做**不同延迟长度**（如 331 ms / 337 ms）→ 两路在不同频率相互抵消 → 读作"宽度"和"色彩"

### 2.5 噪声是幽灵（Noise as Spectre）

噪声不是"脏"，是**时间与空间的证据**：

- 类型选择：磁带嘶声（static）、黑胶爆豆（crackle）、环境田野录音、电路底噪
- 用法一 **质地**：宽带低电平噪声（-45 ~ -60 dB）铺底，让数字音源"落地"
- 用法二 **时间标记**：噪声随段落开启/关闭，比加一轨 pad 更能标记"进入另一个空间"
- 用法三 **掩蔽的反面**：噪声用来**暴露**空间（让人听见"这里有个房间"），不是用来盖住缺陷
- ⚠️ 噪声必须**有频谱形状**（做 tilt/带通），白噪声直铺 = 嘶嘶声，不是氛围
- 噪声与信号的电平关系要**耦合**：信号弱时噪声相对明显（真实磁带的行为），固定电平的噪声层一听就假

## 3. 参数耦合：一个好旋钮改变多个维度

Koçer 反复强调的机器观：**旋钮不是独立参数，是物理联动的结果**。

设计 macro / 表演控制时按"耦合"思维：

| 你想要的听感 | 联动的一组参数 |
|:--|:--|
| "磁带变慢" | 延迟时间↑ + 低通↓ + 噪声↑ + 失谐↑ |
| "进入水下" | 低通↓ + 混响湿↑ + 高频瞬态↓ + 轻微失谐 |
| "打开空间" | pre-delay↑ + 早期反射↓ + 长尾湿↑ |
| "逼近" | 干声↑ + 低通开 + 瞬态保留 + 混响湿↓ |

**反模式**：只调一个参数去做"整体感觉"的变化——听感上永远是"效果器被打开了"，而不是"世界变了"。

## 4. 分层解剖法（任何音色都可拆）

以 kick 为范式（Koçer 的三层解剖），推广到所有音色：

**Kick 三层**

| 层 | 频段 | 作用 | 时长 |
|:--|:--|:--|:--|
| sub | 30–60 Hz | 先于大脑作用于身体（"sub activates body before the brain decides it's music"） | 80–150 ms |
| thump | 100–200 Hz | 质量错觉、冲击的"肉" | 30–80 ms |
| click | ~2 kHz | 神经对齐、节奏的晶体标记 | 3–10 ms |

调整顺序：**先 sub 定身体，再 thump 定重量，最后 click 定清晰度**。三层各自独立处理，不要用一个 EQ 一把梭。

**推广模板**（任何音色都可问这四个问题）：

1. **sub / body**：什么在支撑"存在感"？（低频、基频）
2. **attack / click**：什么在标记"发生"？（瞬态、2–5 kHz）
3. **texture / air**：什么在提供"质地"？（噪声、颗粒、5 kHz+）
4. **space / tail**：什么在说明"它在哪"？（混响、延迟、早期反射）

四层都答不出来 = 音色还没设计完，只是在选预设。

## 5. 宽度、相位与单声道

- 宽度来自**去相关**：两路信号在不同频率相互抵消 → 听感是宽和彩，而不是"左右各放一个"
- 常用做法：双延迟（不同长度）、双 chorus（不同速率）、M/S 只对侧信号加混响
- ⚠️ **必查单声道兼容**：任何宽度手法都要 mono 折叠测试，相位抵消导致主唱/贝斯消失是经典事故
- 低频永远居中（<120 Hz 单声道化），宽度只给中高频
- "在那个长度上，没有东西重复"——长延迟/长混响天然产生去相关，比插件式立体声扩展更自然

## 6. 听感验收（必须"在运动中"判断）

静态频谱图会骗人。验收按"动"来做：

- [ ] **20 秒 solo 测试**：持续音/loop 播放 20 s，听是否有缓慢演化；完全静止 = 死
- [ ] **重复测试**：同 4 小节跑 8 遍，第 1 遍与第 8 遍应可辨差异（变暗/偏移/噪声不同）
- [ ] **Mono 折叠**：折叠后主元素不消失、低频不塌
- [ ] **噪声耦合**：信号静音时噪声底是否随之降低（固定噪声层 = 假）
- [ ] **宏观指标**（可选量化）：
  - 频谱重心：与人声/吉他等"实体"音色不同，氛围类通常在 300–900 Hz 漂移
  - 左右声道相关性：0.2–0.6 为"宽但不空"，>0.9 太窄，<0.1 单声道塌陷风险
  - 峰值因数（crest factor）：氛围 12–18 dB，打击类 8–12 dB
- [ ] **换环境试听**：耳机（orphic 私听）与音箱（共享空间）各一遍——两种场景听到的是两个作品

## 7. 快速配方（可直接落地的四个起点）

**A. Dub chord（经典）**
锯齿/方波 3–4 振荡器 → 低通 800–1.5 kHz（LFO 极慢 ±5%）→ 短促包络（decay 150–300 ms）→ 双延迟 331/337 ms，反馈 0.65，反馈环内低通 3 kHz + 每圈失谐 → 长混响 15% 湿。

**B. Drift pad**
4 个振荡器 ±7 音分独立漂移、相位重置关 → 慢起音 1.5–3 s、长释音 4–8 s → 低通 2 kHz 缓慢游走（LFO 0.03–0.08 Hz，深度 15%）→ 噪声层 -52 dB 带通 1–6 kHz → 混响 decay 6 s、高通 300 Hz。

**C. 有物理感的 Kick**
正弦 55 Hz 起音下滑到 42 Hz（80 ms）→ 三角/正弦 120 Hz 短包络（50 ms）为 thump → 2 kHz 噪声 5 ms 为 click → 轻饱和 → 全部单声道。三层电平比约 0 dB / -6 dB / -12 dB，按曲风微调。

**D. 磁带感回声**
延迟时间 250–600 ms（与速度联动低通）→ 反馈 0.6 → 环内：低通随圈数递减 + 失谐 +3 音分/圈 → 输出端叠 -58 dB 嘶声（高频 tilt）→ 干湿 30%。

## 8. 反模式（历史踩坑）

- ❌ 用**一个全局 LFO** 假装"不稳定"→ 整齐抖动，一听就假
- ❌ 随机不设稳定种子 → 渲染不可复现、分段渲染随机只在第一段生效
- ❌ 噪声固定电平铺底 → 假；必须与信号电平耦合
- ❌ 宽度靠插件一键立体声化 → mono 折叠塌陷
- ❌ 空间只靠末端挂一个混响 → "效果器味"而非"场所感"
- ❌ 用一个参数做整体变化 → 听感是"旋钮被转了"，不是"世界变了"
- ❌ 把噪声当遮羞布盖住编曲/混音缺陷 → 越盖越脏
- ❌ 只看静态频谱图验收 → 声音是时间艺术，必须在运动中判断

## 9. 与工程实现的接口（做引擎/采样时的对应关系）

| 哲学概念 | 工程实现 |
|:--|:--|
| 自发重复 | round-robin 采样组 / `seq_length+seq_position` / lorand-hirand |
| 确定性随机 | 以 `(occurrence, note, channel)` 为键的哈希派生种子 |
| 参数状态即材料 | CC 初始状态播种（`set_cc` 语义），而非仅运行时事件 |
| 分层解剖 | velocity layers + 分频段独立处理 |
| 物理耦合 | 一个参数改动触发多个下游参数的联动表 |
| 听感验收 | 峰值/相关度/重心/crest 的自动回归测试 |

> 判断标准始终是：**换掉设备、换掉播放环境，声音是否还"活着"。**
