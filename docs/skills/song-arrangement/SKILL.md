# 编曲 Skill（曲式与声部写作）

核心方法论：**先定角色，再定音区，最后写音符；写完必须用数据验收，不靠耳朵主观判断**。

## 1. 参考学习法（Style Reference First）

改风格类需求（"太欢快""太违和"）禁止凭感觉重写，按此流程：

1. **选定 2–3 首同风格参考曲**（同乐队/同年代/同情绪）。
2. **逐轨提取量化特征**，而不是听感描述：
   - 各乐器音高区间（MIDI 音符 min/median/max）与频谱重心（Hz）
   - 节奏密度：每小节音符数、同音重复率、休止分布
   - 力度范围（velocity 分布）、段落间能量差（副歌−主歌 dB）
3. **逐项对齐**：把自己工程里对应轨的特征算出来，和参考逐项比，偏差最大的先改。
4. 常见"违和"根因排序：**音区偏高 > 节奏太碎/太满 > 力度太平 > 音色错**。先查前三个，最后才怀疑音色。

## 2. 声角色与音区（每个声部先回答三个问题）

写任何一轨前必须明确：

| 问题 | 典型答案 |
|:--|:--|
| 它的功能是什么 | 根盘/律动/和声填充/对旋律/华彩 |
| 它的音区在哪 | 见下表 |
| 它的节奏性格是什么 | 长音铺底/均匀八分/切分/空拍留白 |

**音区经验表**（ MIDI 音符）：

- 贝斯：低音区 E1–G2（28–43），根音为主；频繁上探到 C3 以上必然"欢快"
- 节奏吉他：把位放在中低把位（约 E3–B3 基音区），riff 单音为主，**每 4 小节留 1 拍真空**给鼓和呼吸
- 键盘/-pad：C3–C5，避免和人声主旋律音区重叠
- 主旋律（人声/主奏）：以参考曲主唱舒适音区为准，不要为"气势"整体抬调
- 鼓：kick 在 40–60 Hz 撑底，军鼓 180–250 Hz 打基频，避免用军鼓音色当律动主角

**根音表要单独校准**：和弦根音→贝斯音高的映射表按参考曲实测写，不要套"默认高八度"直觉。这是历史上最容易翻车的点（整体音高偏高 8–10 半音的典型根因）。

## 3. 律动与重复率

- 贝斯/律动声部：**同音重复率 ≥70%** 是"稳定律动"的硬指标（参考曲实测常到 75–93%）；低于 60% 听感就是"旋律化、抢戏"
- 大跳（≥5 半音）音符占比控制在 <10%，除非是经过句
- 副歌提能量优先用：**加声部/加密度/加力度**，其次才是抬音高
- 段落对比量化目标：副歌−主歌 RMS 差 ≥1.5 dB
- riff 设计：单音 riff 比和弦 riff 更"沉"；每小节 16 分格均匀落点 + 关键拍真空 = 摇滚律动的骨架

## 4. 力度

- 律动声部 velocity 不低于 80，主歌 90–105、副歌 105–120
- 避免全曲同一 velocity：±10 的呼吸感必须保留
- 人声/主奏轨前后乐句力度差 3–6 是"有情绪"的下限

## 5. 验收清单（写完必跑）

用脚本量化自己曲子，与参考对比：

- [ ] 每轨音符区间 median 是否落在目标音区
- [ ] 贝斯同音重复率 ≥70%，大跳率 <10%
- [ ] 频谱重心与参考差 <20%（贝斯参考 ~145 Hz 量级）
- [ ] 副歌−主歌能量差 ≥1.5 dB
- [ ] 各轨无音区重叠打架（贝斯 vs 吉他低音区、pad vs 人声）
- [ ] 全曲时长、段落排布与需求一致

**不达标就回第 2 步重写对应声部，不要试图用混音 EQ 掩盖编曲问题。**

## 6. 反模式（历史踩坑）

- ❌ 用统一的"音高映射表"横跨所有乐器 → 各声部音区错位
- ❌ 为了"丰富"给律动声部加旋律化走音 → 破坏律动感
- ❌ 副歌只靠抬八度 → 听感突兀且挤压人声
- ❌ 编曲问题用混音手段补救（EQ 大砍、压限猛压）→ 越混越糟
- ❌ 只听整体不做分轨量化检查 → 违和感定位不出来
