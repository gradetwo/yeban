# 混音与母带 Skill

核心方法论：**混音是"让位"不是"美化"——每轨先想清楚给谁让什么频段；导出后必须量化验收（峰值/LUFS/时长/逐字节对比），不达标的混音不算完成**。

## 1. 增益结构（顺序不能乱）

1. 先定 **混音总线目标**：流行/摇滚母带峰值 −1.0 dB、整曲 LUFS −9 ~ −14 量级
2. 各轨 solo 调基础电平：人声/主奏 −6 dB 量级起，律动轨往后排
3. 再做**相对平衡**：主歌听人声清晰度，副歌听整体能量，反复 A/B
4. 最后母带级：总线 EQ 微调 → 压限 → limiter 收峰值到 −1.0 dB

**规则：音量平衡问题用推子解决，先推子后 EQ 后效果器。** 推子解决不了的才是 EQ 问题。

## 2. EQ 让位（核心手法）

每个频段分配表（摇滚/流行参考）：

| 频段 | 主角 | 让位手段 |
|:--|:--|:--|
| 40–80 Hz | kick + 贝斯 | kick 给 50–60 Hz 钟形提升，贝斯在 200 Hz 补身体，互让 |
| 180–250 Hz | 军鼓/人声胸腔 | 其他轨此处 dip −2~−3 dB |
| 500 Hz–1.2 kHz | 人声可懂度 | 吉他/键盘整体让位，此处浑浊全是别轨造成的 |
| 1.8–4 kHz | 人声齿音/吉他刺音 | **吉他刺音用反向窄带砍**（如 1800 Hz −6.5、2600 Hz −7.5、4000 Hz −8），配 lpf ~4.6 kHz 收顶 |
| 5 kHz+ | 镲/空气感 | 只给鼓轨和 pad 留，节奏轨 lpf 收掉 |

要点：

- 砍刺用**窄 Q 反向砍**（surgical dip），不要宽 Q 大面积削，否则音色变闷
- 一次只调一处，A/B 对比确认"更清楚"才保留
- 别轨让出的频段，主角轨可以 +1~2 dB 微提，先让后提

## 3. 效果器用法

- **压缩**：律动轨轻压（ratio 2:1–4:1，gain reduction 2–4 dB），人声中压；总线母带压缩 GR 不超过 3 dB
- **混响/延迟**：只给人声/主奏/点缀轨；律动轨（贝斯/节奏吉他/kick）干声，糊都糊在这
- **饱和/失真**：留给母带总线或主奏轨的音色塑造，不要当成响度手段（响度靠 gain 和 limiter）
- 鼓组只做轻补（shaper 微调瞬态），采样库自带音色已足够，别叠效果链

## 4. 导出规范（stem/分轨/工程）

- **分轨导出**：每轨从头到尾等长导出（不留 head/tail 差异），方便对齐；命名带序号与乐器名
- **采样率统一**：分轨源采样率必须与工程一致；不一致时**导入前显式重采样**（如 `resample_poly` 44.1k→48k），否则静默偏移/劣化
- **工程文件**：删轨/改路由后必须检查路由图无孤儿节点（残留源节点会导致渲染失败）；交付工程时连素材路径一起打包
- **母带文件**：峰值 −1.0 dB（防 clip + 防编码过载），真峰值检查 <0 dBTP

## 5. 量化验收（导出后必跑）

- [ ] 总时长与工程一致（±0.5 s）
- [ ] 峰值 −1.0 dB，无 clip（无贴 0 dBFS 的平顶波形）
- [ ] 各分轨峰值/均值电平在预期范围（贝斯/鼓 ≠ 静音：峰值 0.0000 = 路由或 CC 问题，立即排查）
- [ ] 整曲频谱重心合理（摇滚整曲 ~800 Hz 量级；重心突然上飘 = 高频轨刺出）
- [ ] 副歌−主歌能量差 ≥1.5 dB（太平 = 压限过度或编曲没对比）
- [ ] 回归场景（只改部分轨）：改动轨与未改动轨分别比对，**未改动轨必须逐字节不变**，防止"顺手改坏"

## 6. 故障速查

| 症状 | 排查顺序 |
|:--|:--|
| 某轨导出全静音 | 路由图节点/边 → CC 门未播种 → 键位映射缺失 → 采样路径 |
| 导出时长不对 | 源采样率不一致 → 导入器未重采样 → 工程头设置 |
| 删轨后渲染失败 | 路由图孤儿源节点残留 |
| 人声听不清 | 500 Hz–1.2 kHz 被谁占 → 推子先降 → 再 EQ 让位 |
| 整体发闷 | 总线/母带压限 GR 过大 → 吉他未收顶（lpf）→ 齿音处理过度 |
| 副歌不炸 | 先查编曲对比，再查总线压缩是否抹平动态 |

## 7. 反模式

- ❌ 一上来加效果器链，不先做推子平衡
- ❌ 大 Q 宽带 EQ "美化"每轨
- ❌ 律动轨加混响/延迟
- ❌ 母带用 limiter 猛顶到 0 dBFS
- ❌ 导出不验收，直接交付
- ❌ 混音掩盖编曲缺陷（音区错了 EQ 救不回来）
