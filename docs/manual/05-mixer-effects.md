# 混音台与效果

混音控制台（X / F8）给每条轨道一个通道条：增益推子、声像、静音 / 独奏，
以及这条轨的设备链入口。所有轨道最终汇入主总线（Master）。

## 通道条

- 推子控制这条轨的音量；双击或用「混音 → 主控总线推子归 0dB」
  可以把主控推子一键归零（那是主总线的快捷入口）。
- 静音（Mute）与独奏（Solo）是试听工具：排编曲时常用独奏单轨检查细节。
- 左侧检查器（I）里是同一条轨的通道条细节，与混音台是同一份状态。

## 设备链与效果

- 每条轨有一条设备链：乐器在前，效果器在后，顺序就是信号流顺序。
- 在底部「设备机架」页签里增删设备、开关旁通（Bypass）；
  旁通是逐台设备的开关，关掉一台不等于把它删掉。
- 常用三台可以从「轨道」菜单直接插入当前轨：
  参量均衡 EQ（修频段）、空间混响 Reverb（加空间感）、
  动态压缩 Compressor（压动态、让声音更靠前）。
- 设备参数可以录自动化：在编曲区展开自动化泳道（Cmd/Ctrl+Shift+A），
  参数随时间变化会被记进工程、导出时一并生效。

## 宏与级联映射

- 底部「宏 (N)」按钮打开右侧宏面板；N 是当前展示轨的宏数量。
- 每条宏一行：名称、滑块、百分比。拖动滑块改变宏位置，范围 0–100%；
  松手才提交一次 `Op::SetMacro`。拖动期间如果展示轨或工程值变了，这次手势会放弃，不写入。
- 滑块下方「级联去向」是只读摘要，例如「音量 +6 · 声相 -0.5」：
  它说明这个宏会推动哪些目标、推多少；没有映射时显示「无映射」。
- 当前面板只改宏位置：不新建 / 删除宏，也不建立 / 改绑 / 删除映射。
  模型侧已有 `Op::SetMacroMappings` 写路径，但面板尚未接线。

## 监听控制室

- 「混音 → 显隐 监听控制室（Control Room）」：独立的主控监听区，
  看主总线的电平与响度读数，调总音量时不碰任何一条轨道的推子。
- A / B 监听组：A 为近场主箱（`main`），B 为单声道参考（`alt`）。
  切换会改写引擎的监听总线，状态行同步显示监听名和引擎输出设备。
- DIM 把监听电平衰减 20 dB；MONO 做单声道求和；SIDE 只监听立体声差信号（S=L-R）。
  三个开关彼此独立，可以叠加使用。
- 响度表按 EBU R128 给出 INTEGRATED、SHORT-TERM、TRUE PEAK 三项读数。

## 一个实用的混音顺序

- 先把每条轨的音量大致拉平，再上 EQ 修频段冲突；
- 混响这类空间效果优先放在辅助总线上多轨共用，省资源也统一空间感；
- 最后看控制室的响度读数，用主控推子收尾。
