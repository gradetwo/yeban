# 轨道与片段

一首作品由轨道组成，每条轨道在时间轴上摆放片段（Clip）。片段有两种：
MIDI 片段（里面是音符）与音频片段（里面是录音或导入的音频）。

## 新建与删除轨道

- 「轨道 → + 新建 MIDI 合成器轨（Ctrl+N）」：新建一条乐器轨，
  自带一个合成器，适合写旋律与和弦。
- 「轨道 → + 新建音频轨」：新建一条音频轨，放录音与导入的音频片段。
- 「轨道 → + 新建辅助总线轨」：新建一条辅助总线（Aux），多条轨道可以
  把信号送到这里统一处理（例如共用一台混响）。
- 「轨道 → 删除当前选中轨道」：删掉当前选中的轨道。
- 「轨道 → 均分所有轨道高度」：把编曲区里所有轨道的行高拉齐。

## 给轨道装乐器与效果

- MIDI 轨的乐器在底部「设备机架」里换；也可以「文件 → 装载 SFZ 音色库...」
  给当前轨装一份 SFZ 音色。
- 「轨道」菜单可以直接给当前轨插入三台常用效果：参量均衡 EQ、
  空间混响 Reverb、动态压缩 Compressor；更多设备在设备机架里加。

## 摆放与编辑片段

- 在轨道的空白处新建片段后，到钢琴卷帘里写音符（MIDI 片段），
  或把导入的音频摆放到音频轨上（「轨道 → 将最新导入音频摆放到当前音频轨」）。
- 选中片段后：Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+X 剪切；
  拖动改位置，拖边缘改长度，静音开关让片段暂时不出声。
- 「文件 → 导入 MIDI 文件...」把外部 MIDI 的音符导进来；
  「文件 → 导入音频文件...」把音频文件导进素材池。

## 录音

- 「文件 → 实时录音至 WAV...」：把实时演奏 / 播放录成一份 WAV 文件。
- 走带栏的预备拍（Ctrl+Alt+D）打开后，录音与播放前会先数预备小节。
