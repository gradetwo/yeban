# 夜半 Yeban 用户手册

本目录是夜半的用户手册源文件（Markdown）。应用内「帮助 → 用户手册」直接读取
本目录的章节呈现，因此**章节清单与顺序以本文件为准**，新增章节必须同时
登记到 `crates/yeban-app/src/manual.rs` 的章节表里（判据会逐项对账）。

## 章节

| 章节文件 | 标题 |
| :--- | :--- |
| `01-overview.md` | 界面总览 |
| `02-projects.md` | 新建与保存工程 |
| `03-tracks-clips.md` | 轨道与片段 |
| `04-piano-roll.md` | 钢琴卷帘编辑 |
| `05-mixer-effects.md` | 混音台与效果 |
| `06-export.md` | 导出音频 |

## 写作约束

- 只写应用里**真实存在**的功能：菜单项、快捷键与对话框以当前版本为准。
- 快捷键写法与应用内「帮助 → 快捷键速查」同源（`--print-shortcuts` 策略表），
  本手册只引用其中已落地的键位。
- 只使用这几种 Markdown 结构：`#` / `##` / `###` 标题、`-` 列表、普通段落、
  代码围栏。应用内阅读器按行渲染，不支持表格与图片。
