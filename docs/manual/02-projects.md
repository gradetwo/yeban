# 新建与保存工程

夜半的工程文件扩展名是 `.yeban`，它是唯一的工程格式：一个容器文件里装着
工程的全部内容（轨道、片段、音符、设备链与所用素材）。

## 新建工程

- 「文件 → 新建空白工程」：得到一个只有主总线的空工程。
- 启动应用但不指定工程时，会先打开启动工程选择器：可以新建工程、打开最近工程，
  或从「演示工程 / 模板」以未命名副本开始。演示和模板内容不是你的作品文件，
  随便改不会回写原文件。

## 打开工程

- 「文件 → 打开 / 恢复工程...」：在文件对话框里选一个 `.yeban` 文件。
- 命令行也可以：`yeban-app --open <路径>` 直接打开指定工程。

## 保存工程

- 「文件 → 保存工程（Ctrl+S）」：把当前工程写回原文件。
- 「文件 → 另存为（Ctrl+Shift+S）」：换一个文件名或位置保存。
- 保存是原子写入：写一半断电也不会留下半个文件。

## 撤销就是版本

- 夜半没有单独的「历史版本」功能：每一次编辑都是一次提交，
  Ctrl+Z 撤销、Ctrl+Shift+Z 重做，都是在这条提交链上移动。
- 「编辑 → 编曲版本时光机」把整条提交链画成图谱：点任意一个版本节点，
  工程就回到那一版；更早的版本如果画布放不下，面板会如实报出没画出的数量。
