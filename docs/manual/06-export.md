# 导出音频

作品写完后，从「文件」菜单导出。三种出口导出的是三种不同的东西，
不要混用。

## 导出音频（WAV）

- 「文件 → 导出音频（WAV）...」：把整首作品混成一份 WAV 文件。
- 对话框里可以设：输出路径（Ctrl+O 浏览）、采样率、位深、
  导出时长（秒），以及母线限制器开关。
- 默认值：采样率填 `auto`（跟随工程采样率，工程缺省 48 kHz）；位深 `24`；
  时长在打开弹窗时按工程可闻末端预填，空工程或手动清空则回退 8 秒。
- 路径第一次打开时预填 `ui-export.wav`，之后重开保留你改过的值；
  用户自己填过的时长也按原字符保留。
- 16 / 24-bit 导出走 TPDF 抖动，`32f` 浮点原样透传。
- 限制器默认关；打开后只在母线推子/自动化之后、量化之前工作，
  自带 33 帧前瞻并做等量补偿，所以导出长度不变。
- 限制器打开后，渲染会在总线上做峰值限制，防止削波；
  导出回执会报出帧数、真峰值与限制器的工作量。

## 导出分轨（Stems）

- 「文件 → 导出分轨（Stems）...」：每条轨道单独导一份 WAV，
  交给别的软件混音、或送去母带处理时用这个。
- 产物是 32-bit Float、工程采样率的 WAV；文件名 `{4 位序号}.{清洗后的轨名}.wav`，
  汉字保留，路径分隔符等非法字符换成 `_`。
- GUI 默认落点：Windows `%USERPROFILE%\Documents\Yeban\stems`；
  其它平台 `TEMP/yeban-stems`；目录不存在会创建。
- 主总线不出分轨文件，但会在回执的 `skippedTracks` 里点名；
  成功时还会在输出目录写 `stems-manifest.json`，记录每条分轨的
  `trackId`、轨名、文件名、`sha256` 与字节数。
- 目标文件已存在时整批在渲染前拒绝，不覆盖、不跳过、不改名。
- 导出在后台线程进行，完成后状态提示会报出导了几条、跳过几条
  与输出目录。

## 导出 MIDI 文件

- 「文件 → 导出 MIDI 文件...」：把工程的音符导成标准 MIDI 文件（SMF），
  给其他 DAW 或乐谱软件继续编辑。
- 这个入口不弹文件选择器，也没有采样率、位深、时长这类选项；点击后直接按 SMF 写出。
- 落点优先级：`YEBAN_UI_EXPORT_MIDI_PATH` > 工程目录下的 `ui-export.mid` >
  未保存工程写到 `Yeban` 文档目录下的 `ui-export.mid`。
- 完成后回执会报 `path`、`bytes`、`ppq`、`format`、`tracks`、`notes`、`tempos`；
  没有打开工程时如实报错，不生成文件。
- MIDI 只带音符与速度信息，不带音色与效果——那是 WAV / 分轨的活。

## 诊断报告包（不是导出作品）

- 「诊断 → 导出工程诊断报告包」导出的是给排障用的诊断包，
  不是音频；作品有问题要找人看时附上它。
