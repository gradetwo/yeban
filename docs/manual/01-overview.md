# 界面总览

夜半（Yeban）是一款 AI 原生的无头绘画式编曲引擎：每一次编辑都是一条追加进
日志的操作，整首作品是这条日志折叠出来的结果。桌面应用把这份工程投影成
一套可直接操作的编曲界面，本章按区域介绍它。

## 顶部：菜单栏与走带栏

- 菜单栏共九组：文件、编辑、轨道、走带、混音、视图、诊断、设置、帮助。
- 「设置」菜单集中放语言（九种）、质感（扁平 / 实体）、调试输出、
  恢复默认布局，以及音频设备与音源管理入口。
- 走带栏在窗口顶部：播放 / 暂停（Space）、停止、归零到 001.01.000、
  循环播放开关（C）、节拍器与预备拍开关都在这里，还有速度（BPM）显示与敲入。
- 走带栏右侧有工作区切换：全景工作区、现场激发工作区、线性编曲工作区、
  混音控制台工作区（数字键 1–4）。

## 中部：编曲区（轨道区）

- 每条轨道一行：左侧是轨道头（名称、静音 / 独奏、音量），右侧时间轴上
  摆放片段（Clip）。
- 片段可以拖动、拉伸、复制（Ctrl+C / Ctrl+V）、剪切（Ctrl+X）与删除。
- 编曲区上方有小节编号标尺与段落标记；下方可展开和弦轨与自动化泳道（Cmd/Ctrl+Shift+A）。
- 按 Tab 可以打开 Clip 激发矩阵（Session 视图），按格子激发片段。

## 左侧：检查器与音色库

- 左栏上半是通道检查器：当前选中轨道的通道条与设备参数（按 I 显隐）。
- 左栏下半是音色库：预置音色与 SFZ 音色库的浏览入口。
- 轨道头工具行最前面是「轨道菜单」按钮，汇集本轨的操作。

## 底部：控制台三页签

- 钢琴卷帘（P / F7）：编辑 MIDI 音符，见「钢琴卷帘编辑」一章。
- 混音控制台（X / F8）：每条轨道一个通道条，见「混音台与效果」一章。
- 设备机架（F9）：当前轨道的设备链（乐器与效果器）一览与增删。
- F3 把底部控制台最大化 / 还原。

## 右侧与底部边缘

- 右侧可打开监听控制室（Control Room）：主控监听与响度读数。
- 最下方是状态栏：选区信息、实时和弦识别、快捷键提示与音频设备状态。
- 底部还有全曲总览面板：用一张图看全曲的能量与结构分布。

## 悬浮提示与帮助

- 把鼠标停在控件上会出现悬浮功能提示；按 T 可以整体开 / 关。
- 「帮助」菜单里有用户手册、快捷键速查、新手引导与教学课程四个入口，
  第一次启动时应用会自动打开新手引导。

## 常用快捷键速查

- 播放 / 暂停：Space。
- 保存 / 另存为：Ctrl+S / Ctrl+Shift+S。
- 撤销 / 重做：Ctrl+Z / Ctrl+Shift+Z。
- 新建 MIDI 合成器轨：Ctrl+N。
- 展开 / 收起自动化泳道：Ctrl+Shift+A。
- 切换选中片段的静音：Cmd/Ctrl+M；作用域是选中的摆放，整条轨静音用 M。
- 钢琴卷帘：P 或 F7；混音台：X 或 F8；设备机架：F9。
