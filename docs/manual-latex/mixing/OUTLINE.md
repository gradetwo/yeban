## 三、第一章样章要点

1. 混音三个工程目标：可懂、平衡、可控；“好听”属审美判断，不当作可测指标。
2. 信号路径：各轨设备链 → 通道条推子/声像 → 辅助总线或主总线 → 监听控制室。
3. 混音控制台（X / F8）每轨一条通道条；左侧检查器（I）与混音台同一份状态。
4. 监听控制室（F4，或混音菜单）显示主总线积分/短时 LUFS 与峰值 dBTP，提供 DIM（−20 dB）、MONO、SIDE（S=L−R）试听开关；这些开关只改监听方式，不动轨道推子。
5. 参考曲：导入音频、单独音频轨摆放、旁通该轨效果；只做 A/B，不进入最终导出。
6. 七步顺序：粗平衡 → 增益结构 → EQ → 动态 → 空间 → 自动化 → 总线收尾。
