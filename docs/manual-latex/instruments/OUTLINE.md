## 三、第一章样章要点

1. 三条信号路径：MIDI 合成器轨 → 乐器 → 插入效果 → 总线；音频轨 → 音频片段 → 总线；辅助/主总线不挂乐器。
2. 一条轨至多一件音源；同轨多音源时引擎分派次序为“鼓机 > SFZ > 复音合成器”。
3. 新建 MIDI 轨自动安装 `Yeban PolySynth` 并确保到主总线路由；音频/辅助/主总线不插乐器。
4. 六个 `synth:*` 预设的 ID、左栏显示名、底部/编曲区显示名、引擎名对照表；同一预设不同面板文案不同，以 ID/引擎名为准。
5. 原生预制库的两种范围：乐器预制（instrument）与整轨快照（track）；界面“另存当前轨为预制”走乐器预制，内置合成器轨/音频轨无可移植乐器身份会被拒绝；整轨设置应存整轨快照或模板。

## 四、第二章样章要点

1. 每轨 16 个在响声部；两条振荡器支路共用五张波表：0 hollow、1 organ、2 vocal、3 metallic、4 glass。
2. 四极梯形低通：截止有效域 20 Hz–0.45×采样率；共振、驱动均为 0–1；驱动 0 逐位旁通，1 为 +36 dB 预增益。
3. 固定 ADSR：5 ms / 80 ms / 0.7 / 50 ms；当前无 ADSR 旋钮、无 LFO、无调制矩阵；不写假控件。
4. 九个参数名、有效域、默认值完整表：`cutoff_hz`（别名 `cutoff`）、`resonance`（别名 `res`）、`drive`、`osc1_wave`、`osc2_wave`、`osc1_level`、`osc1_detune_cents`、`osc2_level`、`osc2_detune_cents`。
5. 六个预设的九个参数逐项数值表，取自 `crates/yeban-app/src/host.rs` 的 `synth_preset_definition`。
